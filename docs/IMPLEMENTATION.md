## 검증

| 검사                          | 결과                                                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------------------- |
| TypeScript strict             | 통과                                                                                            |
| Vite 네 개 HTML 프로덕션 빌드 | 통과                                                                                            |
| Vitest                        | 38개 통과: 순수 함수 3, 생성기 14, 편집 가능한 코드 예제 구문 21                                |
| Playwright Chromium           | 14개 통과: 데스크톱 7, 모바일 에뮬레이션 7                                                      |
| Storybook 정적 빌드           | 통과                                                                                            |
| 생성 프로젝트 독립 검증       | 세 템플릿 × 옵션 포함/제외 = 6개 설치·타입·프로덕션 빌드 통과; 테스트 포함 3개 단위 테스트 통과 |
| 화면 확인                     | 데스크톱 갤러리, 모바일 라이브러리, Cloudscape 다크 모드 확인                                   |

브라우저 시나리오는 갤러리 검색/상세/뷰포트/테마 유지, Props 및 disabled, 모달 Escape 닫기, CMS 생성/수정/삭제/CSV, Cloudscape 생성/검색/상태 전환, Analytics 필터/KPI, ZIP 다운로드/안전한 이름, 파일 선택과 레이아웃을 다룹니다. Safari/WebKit 및 Firefox는 실행하지 않았습니다. Storybook a11y 애드온 구성은 전체 접근성 감사를 통과했다는 의미가 아닙니다.

검증 환경에는 두 가지 제한이 있었습니다. Storybook이 OS 네트워크 인터페이스 조회에서 실패하여 검증 프로세스에만 loopback fallback을 적용했습니다. 해당 우회 코드는 프로젝트 소스에 포함하지 않았으며 일반 OS에서는 표준 명령을 사용합니다. Playwright 다운로드의 기본 CDN은 잘못된 ZIP을 반환했지만 공식 대체 다운로드 호스트에서 Chromium을 설치하여 실제 테스트를 완료했습니다. 사용 버전은 1.56.1로 고정했습니다.

## 알려진 제한과 남은 작업

- Props 패널은 공통 레이블, Button의 variant/size/disabled/loading과 일부 입력/폼 상태를 지원합니다. 모든 컴포넌트 Props를 자동 추론하는 스키마 에디터는 아직 없습니다. 테이블·필터·탭 등은 미리보기 안에서 상태를 직접 조작합니다.
- Storybook은 Button 상태별 스토리와 모든 예제를 고를 수 있는 Controls 스토리를 제공합니다. 모든 컴포넌트의 개별 exhaustive story·interaction test는 후속 작업입니다.
- Cloudscape 번들은 큰 청크 경고가 있습니다. iframe으로 스타일을 격리했지만 네트워크/청크 최적화는 추가로 진행해야 합니다. 한국어 웹폰트를 포함하고 Cloudscape의 공식 typography token을 런타임에 적용합니다. 빌드 시 테마 생성으로 바꾸는 최적화도 후속 항목입니다.
- CMS·Cloud는 메모리 Mock이며 새로고침 시 초기화됩니다. Analytics 데이터는 결정적 샘플이고 비교 증감률과 유입 비중은 고정 예시입니다.
- FileUpload는 다중 선택·용량 검증·파일명 표시를 제공합니다. 서버 전송, 파일 보관, 업로드 진행률은 구현 범위에 없습니다.
- ZIP 생성기는 현재 제공되는 세 템플릿만 지원하며, 사용자 정의 템플릿 등록/메타데이터 편집/권한 관리는 없습니다.
- 전체 WCAG 감사, 실제 보조기술 검증, 브라우저 다양화 및 E2E 커버리지 확대가 남아 있습니다.
- 백엔드, DB, 인증, 배포는 추가하지 않았습니다. GitHub Actions에는 재현 가능한 검증 명령을 정의했습니다.
